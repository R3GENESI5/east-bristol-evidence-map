# East Bristol Evidence Map

Interactive map of how Bristol City Council measured through traffic in the East Bristol Liveable Neighbourhood before and after the 2024-25 trial, using the council's March 2022 ANPR survey, its 2025 monitoring data pack and OpenStreetMap.

Live page: https://r3genesi5.github.io/east-bristol-evidence-map/

Built by `code/generate_ebln_scheme_map.py v2` in the analysis repository. Analysis: Ali Bin Shahid, October 2026. Map data © OpenStreetMap contributors.
